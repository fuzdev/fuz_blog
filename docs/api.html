Renders a feed as Atom XML, entries newest first (see compare_feed_items). The feed-level <updated> is the latest date_modified or date_published across the items. Atom requires the element, so a feed with no items gets the Unix epoch, 1970-01-01T00:00:00.000Z - a fixed value keeps the generated feed.xml deterministic, where the current time would change it on every gro gen. Expects parsed Feed data; an unparseable date throws.

find_blog_post_dir
#

blog_post_dir.ts view source

(post_dirs: BlogPostDir[], query: string, blog_dirname: string): BlogPostDir import {find_blog_post_dir} from '@fuzdev/fuz_blog/blog_post_dir.js';

Finds a blog's post by a query naming it: a bare id like 1 matches by id, an <id>-<slug> directory name like 1-hello-world matches that directory exactly, and anything else matching BLOG_POST_SLUG_PATTERN matches by slug. A directory name that matches no post falls back to matching by slug, since a slug may itself look like <id>-<slug> (5-1-x has the slug 1-x). An existing directory name wins over an equal slug of another post. Slugs are not unique across ids, so a slug matching more than one post throws - query by id or directory name instead.
