create_blog_gen_outputs
#

blog_helpers.ts view source

(options: BlogGenOptions): BlogGenOutput[] import {create_blog_gen_outputs} from '@fuzdev/fuz_blog/blog_helpers.js';

Creates the gro gen outputs for each blog: its feed.xml, its feed.ts, and, when it has posts, its [post=blog_post_id] redirect route. A blog without posts gets no redirect route, because prerendering fails on a dynamic route with no entries. The feed's atom.feed_url is derived from home_page_url by to_blog_feed_url.

options

type BlogGenOptions

returns

BlogGenOutput[]

throws

  • Error - on an invalid blogs registry (see `validate_blog_configs`), invalid post metadata, a post whose `date_modified` precedes its `date_published`, a feed that fails validation, or a redirect route left on disk for a blog without posts (gen cannot delete it)

(options: CreateBlogPostOptions): Promise<CreatedBlogPost> import {create_blog_post} from '@fuzdev/fuz_blog/blog_helpers.js';

Scaffolds and writes the next post file for config at <id>-<slug>/+page.svelte, returning its id, path, and slug. The id is one more than the highest existing id. Does not run gen - callers invoke that afterward (see post.task.ts).

throws

  • Error - when no slug is given and none derives from `title`, or the slug does not match `BLOG_POST_SLUG_PATTERN`
